# BotStudioAI
Creación de bots


## Estructura del proyecto
- `app/src/main/java/`: codigo de la aplicacion Android.
- `app/src/main/AndroidManifest.xml`: permisos y Activity.
- `app/build.gradle`: configuracion de Android 16.
- `.github/workflows/android.yml`: compilacion automatica.

Los APK de prueba se descargan desde GitHub Actions > Artifacts.
No publiques claves API en GitHub.
